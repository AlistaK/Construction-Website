# BuildPro Construction

A modern, responsive website for a fictional construction company specializing in residential construction, commercial buildings, and renovation projects.

## About the Project

BuildPro Construction is a website project developed as part of the Programming Fundamentals with AI course.

The website presents the company's services, completed projects, and business information through a clean and professional design.

## Features

- Responsive website layout for desktop and mobile devices.
- Navigation menu with links to the main sections.
- Hero section introducing the company.
- Services section featuring three main construction services.
- Completed Projects section showcasing three example projects.
- Why Choose Us section highlighting the company's values.
- Contact information and footer section.
- Construction-themed visual design using navy blue, white, grey, and orange.

## Services

- Residential Construction
- Commercial Construction
- Renovation & Remodeling

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Copilot (AI-assisted development)

## Getting Started

To view the website locally:

1. Clone the repository:

   `git clone https://github.com/AlistaK/Construction-Website.git`

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or use the Live Server extension.

## Live Preview

The website can be viewed locally using Visual Studio Code and Live Server.
